# Sakina Mobile Live Demo Plan

## Demo Goals
- Show end-to-end mobile to backend flow in staging.
- Demonstrate RAG answer with citations.
- Demonstrate admin visibility into basic telemetry.

## Demo Steps
1. Launch mobile app in staging mode.
2. Authenticate test user.
3. Fetch modules and sync state.
4. Ask a knowledge question and inspect citation output.
5. Show dashboard health endpoint and release metadata.

## Readiness Checklist
- Staging backend URL reachable.
- DB migrations applied.
- RAG retrieval test pass.
- Smoke scripts pass.
