PROJECT OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

Project Sakina is a complete enterprise-grade AI system designed to:

✅ Run entirely locally (no cloud APIs, no data exfiltration)
✅ Prevent hallucinations (strict RAG with 0.85 similarity threshold)
✅ Encrypt all data (AES-256 at rest, TLS 1.3 in transit)
✅ Maintain audit trails (append-only logging for transparency)
✅ Support both languages (Arabic with proper RTL, English)
✅ Work offline (local models, no internet required after init)

INSTALLATION FLOW
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Run Platform Setup (15-30 minutes)
────────────────────────────────────────────
  macOS:  chmod +x macos-setup.sh && ./macos-setup.sh
  Linux:  sudo chmod +x linux-setup.sh && sudo ./linux-setup.sh
  Windows: .\setup-sakina.bat

STEP 2: Run Main Setup (5-10 minutes)
────────────────────────────────────────────
  All platforms: chmod +x setup-sakina.sh && ./setup-sakina.sh

STEP 3: Initialize Kubernetes (5-15 minutes)
────────────────────────────────────────────
  cd SakinaAL
  make setup-k8s        # Creates cluster with namespaces

STEP 4: Start Services (5-10 minutes)
────────────────────────────────────────────
  make dev-start        # Deploys PostgreSQL and Qdrant
  make deploy           # Deploys API, vLLM, and services

STEP 5: Verify Everything (2 minutes)
────────────────────────────────────────────
  make health           # Checks all services

TOTAL TIME: 40-75 minutes (depending on internet speed and computer specs)
